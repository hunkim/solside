The browser with a sun in its side panel.

Solside pairs everyday browsing with an assistant that reads the page, answers questions, and can click, type and scroll for you.

Download for macOSSee features

Everything in one window

A small, focused set of features. This is an early prototype; the list below is what exists today.

Tabs and address bar

Open pages in tabs, type a URL or a search term, and use back, forward and reload.

Bookmarks sidebar

Star a page to keep it in the sidebar for quick access.

Assistant panel

Summarize the current page or ask questions about it in a chat side panel.

Agent actions

Let the assistant click, type, scroll and navigate in a few steps. Each step is shown in the chat.

Persistent sessions

Stay signed in between launches, and re-run past tasks from the recent list.

Your own API key

The assistant uses a model endpoint you configure. The key stays in your environment, not in the app.

Designed around Solar

The default model setting points at an Upstage Solar model through an OpenAI-compatible endpoint. Any compatible model can be swapped in with AI_MODEL and AI_BASE_URL.

The sun-and-sidebar mark, the violet night sky and the amber glow are a nod to that idea. Solside is an independent hobby project and is not an official Upstage product.

Good to know

Honest notes about this prototype.

Agent safety

The agent can act on pages you are signed in to and has no approval step yet. Use it with care and keep an eye on each step.

Unsigned build

macOS builds are not signed or notarized. The install notes explain how to open them.

Not yet built

History, download manager, private windows, extensions and drag-to-reorder tabs.
