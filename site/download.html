Install

  1. Easiest: double-click the .zip (Safari/Finder unzips it) and drag Solside.app into Applications. With the .dmg, open it and drag Solside.app onto Applications.
    2. Solside.app onto Applications.
  2. The app is not signed or notarized, so macOS Gatekeeper may block it. Either right-click the app in Applications and choose Open, then Open again, or run in Terminal: 
    xattr -cr "/Applications/Solside.app"
  3. If macOS says the app is "damaged" or it will not launch (Apple Silicon needs a valid code signature), re-sign it locally with an ad-hoc signature: 
    codesign --force --deep --sign - "/Applications/Solside.app"
  4. For AI features set AI_API_KEY (and optionally AI_BASE_URL, AI_MODEL) in the environment.

The .dmg is an HFS+ disk image built on Linux and has not been tested on a real Mac. If it does not open, use the .zip.
